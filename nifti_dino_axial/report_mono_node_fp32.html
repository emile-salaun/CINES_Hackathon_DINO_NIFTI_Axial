MI300A — scaling DDP b10 vs b40 (mono + multi-node) — mesures fp32

⚠️ Mesures fp32 faites sur HPE_adastra branch AVANT le switch dev en bfloat16 (commit dev da20e9f). Les chiffres ici sont une référence historique : avec le bf16 actif sur dev_hpe, les valeurs réelles seront probablement supérieures (throughput). Logs bruts archivés sous scripts/logs/MI300_fp32/.

8 runs (6 mono-node, 2 multi-node) sur Adastra (réservation hackaton), batch=10 et 40, BIND_STRATEGY=mi300_numa (mono) ou mi300_srun4 (multi). Mesures warm step 100-200, config confirmé via le log Effective:.

3 takeaways :
  • Champion actuel : 4n × 4 APUs × b40 → 217.6 img/s → 10M en 0.53 jours
  • b40 sature progressivement : DDP eff 100% → 85% → 68% → 58% (drops -15/-17/-10pt). Le saut inter-node (4→8 cross-node) a perdu MOINS que les intra-node.
  • b10 reste plat intra-node (100% → 86% → 83%) — à grande échelle, b10 pourrait dépasser b40 (à tester en multi-node)
